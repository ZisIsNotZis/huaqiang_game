# Code of Conduct

This project welcomes focused, respectful collaboration. Assume good intent, discuss ideas rather than people, and make criticism specific and actionable.

Unacceptable behaviour includes harassment, discrimination, threats, doxxing, sexualised conduct, and knowingly submitting copyrighted or confidential material. The project owner may remove comments, reject contributions, or restrict participation when needed to keep the project safe.

Report conduct concerns privately through the repository owner’s GitHub profile. Do not open a public issue for sensitive personal information.
