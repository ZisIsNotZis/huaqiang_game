# Phase 2 阶段门

## 实现范围

已建立可执行的低保真事件规则原型，公开接口为：

```python
play_scenario(actions: list[Action]) -> EventResult
```

当前验证四条路径：

1. 观察秤、邀请证人、让摊主报价、公开磁铁并要求退款：不战而胜。
2. 掌握相同事实但没有证人：受到威胁后离开。
3. 预先安排摩托和卡位，在无证据对峙后推开对方撤离：受控冲突。
4. 预先带刀并首先攻击：现场占优，但街坊和警方版本都不利。

## 自动验收

- [x] 同一事件存在非暴力、受控冲突和严重失控结果。
- [x] 公开证人会改变相同证据的结果。
- [x] 空间与撤离准备会改变冲突结果。
- [x] 首先攻击不会成为无代价最优解。
- [x] 结果分别输出客观事实、证人知识、街坊版本和警方版本。
- [x] 公共接口由行为测试覆盖。
- [x] 提供可由所有者直接运行的命令行试玩。
