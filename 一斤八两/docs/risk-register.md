# 项目风险登记表

## 使用规则

- 每月至少复查一次，每个阶段门前必须复查。
- AI 负责持续检查和提出缓解措施，zisisnotzis 负责需要所有者判断的最终裁决。
- 概率与影响使用低 / 中 / 高。
- 任何已触发的高影响风险都必须进入任务系统，不得只保留在文档中。
