# Phase 4 进度：Godot 垂直切片基础版

## 本轮完成

- 锁定 Godot 4.7.1 作为垂直切片引擎。
- 官方 Linux 二进制已校验 SHA-256。
- 将事件状态机迁移为独立 GDScript 公共接口。
- 先建立失败测试，再实现并通过非暴力完整路径。
- 建立程序化 3D 街市灰盒：
  - 街道、人行道、瓜摊、秤、瓜、修表铺、干洗店、通道和摩托。
  - 玩家、摊主、两名帮手和可出现的证人。
- 支持 WASD / 方向键角色移动。
- 运行时使用第三人称跟随相机；自动截图使用固定总览镜头。
- 行动已绑定到秤、修表铺、摩托、木凳和摊主附近，玩家必须移动到合理距离。
- 支持逐步社会与空间行动、NPC状态、事件日志和双版本结算。
- 冲突触发红色警示与帮手逼近；受控撤离触发玩家移动演出。
- 每次行动写入本地检查点，并支持重开事件。
- 摊主通过可测试的距离与视角规则观察玩家，界面显示“看见 / 未看见”及原因。
- 视线使用真实3D物理射线检测瓜摊和建筑遮挡。
- 可疑准备行为根据是否被看见决定是否增加摊主警觉。
- 声音使用可测试的距离、响度和遮挡衰减；拖动木凳可通过听觉暴露。
- 摊主警觉达到阈值后会向前靠近，提供可见的行为反馈。
- 冲突结果依据退路、卡位和对手支持计算无伤、轻伤或重伤。
- 无准备冲突不再形成无动作死锁；玩家可付出持续伤势强行逃离。
- 自动渲染并检查了无伤与重伤两种结算画面。
- 世界互动改为选择最近有效目标，只显示一个上下文行动。
- 目标使用发光材质高亮，`E` 提示增加深色描边；已通过实际渲染修复低对比度问题。
- 设置与无障碍面板支持主音量、文字缩放和减少运动，并持久化到本地。
- 减少运动会用即时状态变化替代冲突、接近和逃离的大幅补间动画。
- 设置面板已通过实际引擎渲染检查，无溢出或遮挡问题。
- 场景主要方块与玩家已加入基础碰撞。
- 单一可用行动可以用 `E` 执行，`Esc` 可暂停；支持读取最近检查点。
- 建立测试、运行和截图脚本。
- 使用真实 Godot 渲染初始与结算画面，并修复首次截图中相机朝向错误。
- 扩展为完整章节流程：妹妹陈述、行动原则、选瓜、公开保熟、称重、揭秤、切瓜与结算。
- 加入妹妹与路人，使现场达到 7 名具备叙事立场或功能的角色。
- 三条主路径均可从开场走到结局：公开施压、准备后撤离、无准备负伤逃离。
- 每条结局提供街坊版、警方版和下一章钩子。
- 加入程序化街市环境声和按行动类型区分的交互 / 冲突提示音；主音量设置控制总线。
- 检查点升级为带版本封装、字段校验、旧格式迁移和损坏存档显式报错。
- 自动测试覆盖完整非暴力章节、准备后撤离、严重负伤、音频规则和存档往返 / 损坏数据。
- 下载并校验 Godot 4.7.1 官方导出模板，生成独立 Linux/X11 构建。
- 独立构建大小约 73.6 MB；无窗口冒烟运行约 1.14 秒退出，峰值常驻内存约 120 MB。

## 视觉检查结论

第二轮截图满足当前灰盒要求：

- 场景已进入镜头且主要空间关系可辨认。
- 角色、摊位、证人位置、通道和撤离交通工具均可见。
- UI与3D场景分区明确。
- 初始状态和非暴力结算状态均无文字溢出或关键遮挡。

已知视觉债：

- 3D人物标签在远景中偏小。
- 程序化方块只用于构图验证，未达到最终资产品质。
- 缺少动画、表情、环境细节、粒子和正式色彩分级。
- 当前等距镜头用于快速验证，并非最终第三人称跟随镜头。
