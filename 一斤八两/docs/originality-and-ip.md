# 原创化与知识产权边界

## 1. 基本原则

《一斤八两》不是电视剧《征服》的改编作品。现有影视片段只用于分析抽象戏剧结构与玩法可能性，不构成使用其具体表达的许可。

本文件是私人项目的操作边界，不是法律意见。当前不营销、不分发、不商业化；若目标改变，应重新评估具体表达和发布风险。

## 2. 可以继续研究和原创实现的抽象元素

- 顾客揭露商贩缺斤短两。
- 通过公开承诺增加社会压力。
- 观察入口、出口、人数和可动物件。
- 改变站位，使多人冲突变成受控局面。
- 为撤离预先安排交通工具。
- 客观事实、证人视角和社会流言不一致。
- 短促、高风险、后果长期存在的冲突。
- 1990 年代末中国北方工业城市的一般历史与生活元素。

这些元素必须与原创人物、原创对白、原创事件顺序和原创视听表达结合。

## 3. 禁止直接使用的表达

- “刘华强”等原作角色名、身份关系和人物传记。
- 演员孙红雷或其他演员的肖像、声音、体态特征和可识别造型复刻。
- 原剧逐字或高度近似台词，包括作为彩蛋、成就名或宣传文案。
- 原剧镜头构图、动作顺序、分镜节奏和回眸画面的逐镜重现。
- 原剧截图、视频、录音、音乐、音效或商标。
- 真实或虚构但可识别的原剧地点、车牌、日期和专有细节组合。
- 暗示获得官方授权、官方续作或与权利方合作的宣传。

## 4. 当前原创设定

- 城市：铁衡市，虚构北方工业城。
- 主角：周烈，前摩托车修理工。
- 核心冲突：调查由商业欺诈、保护费和沉默构成的利益网络。
- 章节事件必须脱离原剧单一桥段，发展为钟表换芯、录像厅敲诈、工业地磅作弊、证人驱散和年货市场危机等原创结构。

上述名称仅用于私人开发；若考虑公开发布，再进行名称和相似角色检索。

## 5. 资产来源规则

每项外部资产必须记录：

- 作者 / 供应商。
- 来源链接或合同编号。
- 许可证全文和商业使用范围。
- 是否允许修改、再分发和用于宣传。
- 是否要求署名。
- 购买或获取日期。

不接受“网上找到”“仅供学习”“AI生成所以一定安全”等来源说明。

生成式工具只可在供应商条款允许商业使用、训练数据与输出权利风险已评估、且不要求模仿在世艺术家或特定影视作品风格时使用。最终资产仍需人工原创性检查。

## 7. 发现风险时的处理

1. 停止继续制作和对外传播相关内容。
2. 在风险登记表中记录来源、影响和负责人。
3. 隔离但不擅自销毁可能需要审计的材料。
4. 用原创替代方案重做，或取得明确书面许可。
5. 由有权限人员记录接受、缓解或拒绝风险的决定。
