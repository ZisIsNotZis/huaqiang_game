# 《一斤八两》项目章程

## 1. 项目使命

制作一款高质量私人单机游戏实验，让玩家通过观察、社会判断和空间安排控制危险冲突，而不是依靠持续战斗清除敌人。6–8 小时是目标规模，不是近期承诺。

## 2. 一分钟提案

《一斤八两》发生在 1990 年代末的虚构北方工业城“铁衡市”。玩家扮演前摩托车修理工周烈，在由黑秤、保护费、假货和沉默构成的利益网中调查并处理一系列街区事件。玩家先观察事实、试探人物、改变站位并安排退路，再面对数秒钟的高风险冲突。系统分别记录客观事实、证人所见和事件流言，所以打赢现场不一定能赢得街坊、警方或未来。

本作不是开放世界犯罪模拟器、格斗游戏或纯对话互动电影。它的差异点是：**每场冲突前的十分钟决定之后的十秒，而事件结束后，别人如何讲述它仍会继续改变游戏。**

## 3. 产品边界

### 计划内

- Windows PC 作为当前开发和试玩平台。
- 键鼠与手柄。
- 5 个高密度半开放街区。
- 10–12 场主要冲突。
- 压力对话、空间预演、短促冲突和现场叙事。
- 单机离线游玩。
- 简体中文为当前唯一必需语言。

### 计划外

- 无缝开放世界。
- 多人或持续在线服务。
- 可自由屠杀的城市沙盒。
- 依赖连招、装备等级和敌人血条的常规战斗循环。
- 影视IP改编、演员肖像复刻或原场景复刻。
- 公开发行、商业营销、主机版本、DLC或发行日期。

## 5. 决策机制

1. **可逆决定**：由对应负责人执行并记录，可在冲刺评审中调整。
2. **高成本或难逆决定**：引擎、平台、完整制作预算、关键外包和发行协议需项目所有者及相关负责人共同批准。
3. **设计争议**：先定义互斥假设和测试指标，再制作最便宜的可玩实验。
4. **阶段门**：制作人汇总证据，负责人逐项签署；任一阻断项不得用口头乐观判断替代。
5. **范围变更**：新增内容必须同时说明移除什么、增加多少成本和影响哪个里程碑。

## 6. 工作节奏

- 原型期：一周一个测试目标，两周一个可分发版本。
- 完整制作期：两周冲刺；期末必须展示可玩构建。
- 每月更新风险登记表。
- 每个阶段结束生成验收报告和明确的 Go / Conditional Go / No-Go 决定。

## 7. 初始预算边界

当前没有预设资金上限，但这不等于允许无约束采购。项目默认使用已有工具、开源或可合法使用的资源，由 AI 优先完成工作。任何实际付费、外包、账号注册或不可逆采购必须由 zisisnotzis 明确执行或批准。
