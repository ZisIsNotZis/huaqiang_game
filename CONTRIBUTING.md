# Contributing

This repository is an experimental collection. Contributions should make an experiment easier to understand, run, or evaluate without expanding its claims.

Before changing the main game, read [`一斤八两/CONTRIBUTING.md`](一斤八两/CONTRIBUTING.md), the relevant phase documents, and the originality/IP boundary. Keep pull requests focused, preserve existing source and evidence, and include the command used to verify the change.

Good contributions include reproducible tests, documentation fixes, accessible UI improvements, small rules experiments, and clearly labelled design evidence. Do not submit secrets, personal data, unlicensed media, or material copied from protected television/game properties. Do not claim external validation, authorization, financing, or release readiness without recorded evidence.

Use Conventional Commits where practical (`docs:`, `test:`, `fix:`, `feat:`). Changes to the game’s scope or core pillars must be discussed before implementation.
